# Paper2Slides：论文转学术 PPT

将科研论文或研究材料组织成可编辑、可讲解、证据可追溯的学术汇报。

本项目以 Skill 形式供 Agent 调用，适用于论文分享、组会汇报和学术演示准备。

## 主要功能

- 提取研究问题、方法、关键结果和局限，组织汇报主线。
- 为每页主张保留论文页码、章节或图表来源。
- 按指定模板生成或修改可编辑 PPT。
- 添加讲稿备注和页面之间的过渡说明。
- 检查演示文件，并通过可用工具生成真实 PDF/PNG 预览。

原论文图可作为来源明确的图片保留；具备准确原始数据时，可生成原生可编辑图表。

## 如何使用

将完整 Skill 目录交给支持 Skill、文件读写和命令执行的 Agent，提供实际论文、任务要求及模板。

调用示例：

> 请使用 evidence-paper-slides，根据提供的论文和模板，
> 制作一份中文学术汇报。遵守任务指定的页数、时长和受众要求，
> 输出可编辑 PPTX、逐页证据映射、讲稿备注及真实渲染预览。
> 对材料缺失、工具不可用或无法核验的内容如实说明。

具体接口与命令见 references/interfaces.md 和 references/usage.md。

## 运行依赖

辅助脚本使用 Python 3.10+，相关功能需要：
python-pptx、PyMuPDF、Pillow。

真实演示渲染还需要可用的 LibreOffice、Office
或其他受支持的导出工具。优先使用运行环境已有的兼容工具。

## 验证状态与限制

已使用明确标注的虚构材料，检查生成、定点修改、
证据定位和真实渲染流程。

尚未运行组织方三个正式案例，不提供未经测量的得分或效率增益。

自动检查不能代替科学内容核验和实际预览检查。
中文字体、复杂模板及目标软件兼容性需在实际环境中确认。
