# Scientific conversion and failure decisions

Read actual methods, results, figures and discussion as well as abstract. Distinguish research question from motivation, new method from adopted methods, main findings from background, demonstrated contribution from future work. Adapt the story to its genre:

* Empirical: question, design/comparison, important evidence, explanation, limits.
* Method: unmet need, method/assumptions, validation, comparison, applicable range.
* Theory: question, definitions, assumptions, reasoning, result, implications.
* Review: scope/search basis, organization of evidence, agreement/conflict, gaps.

Do not force every item into a separate slide. Under short page caps combine setup and retain the strongest evidence and material limitations. Count cover/closing slides within the TOTAL. Use requested language and talk duration.

## Evidence

Assign a purpose and primary claim to each slide. Record physical PDF page number (1-based) separately from printed label, section, figure/table number and panel. Store exact short anchors privately in the ledger and concise locators in notes/on slides as required. Multiple claims on a slide may need different sources.

For numerical statements verify value, unit, denominator, group, direction, time window, interval and test against the source. For derived numbers save formula and operands and label as derived. Check figure identity, panel, legend and ownership visually. Reading only a caption does not verify plotted data. Preserve source images where exact raw values are absent. Do not fabricate a native data chart from estimated pixels.

Speaker notes should add explanation, transitions or likely questions. Keep limitations that alter the meaning of a result visible on the slide. Distinguish original work from cited work and your synthesis. Never imply randomization, causality or statistical significance not present in the source.

## Template and editing

Use actual aspect ratio, master/theme, placeholders and logo/footer rules. Inspect layouts instead of assuming index 1 is suitable. Preserve unrequested slides, objects, charts and notes during adaptation. Record slide, target shape/placeholder, action and reason for each change. Check residual sample titles, diagrams and footers after generation. Preserve source image proportions; required editable text/tables/charts must remain native objects. A whole-slide screenshot fails editability.

## Failure decisions

| Condition | Action |
|---|---|
| Missing template or required source | Report missing_material. Label any useful fallback partial; do not claim compliance. |
| Encrypted/unreadable PDF | Try authorized password or available parser. Identify inaccessible portions. |
| Scanned text/math | Use available OCR/vision, inspect original, mark unresolved signs/characters. |
| Figure extraction failure | Render actual source page and crop verified rectangle, retaining labels and conditions. |
| Insufficient placeholder | Choose compatible layout or measured native shape; log exception. |
| Overflow | Shorten wording or redistribute within page cap before reducing size. Preserve required facts. |
| Font missing | Inspect actual fonts, document substitution, rerender and visually inspect. |
| No renderer | Keep editable deck/checks; mark preview unverified and essential requirement partial. |
| Conflicting evidence | Expose disagreement and avoid unsupported precision/conclusions. |
| Time almost exhausted | Save current deck, evidence and partial result before optional polish. |

## Audit boundaries

Literal-anchor checks establish occurrence, not entailment. OOXML/geometry checks establish package properties, not visual quality. A successful render does not establish PowerPoint playback or scientific accuracy. Do not turn heuristic warnings into invented certainty.
